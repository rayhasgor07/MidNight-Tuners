# 🚗 MidNight Tuners

A full-stack automotive platform built for car enthusiasts, tuners, and performance drivers. Inspired by the legendary **Mid Night Club** — the iconic Japanese street racing club that operated from 1987 to 1999 — MidNight Tuners brings that same passion into a modern digital space where enthusiasts can learn, share, and tune together.

🔗 **Live App:** [midnight-tuners.web.app](https://midnight-tuners.web.app)

---

## Features

### 🤖 AI Tuning Assistant (Groq Powered)
An integrated AI assistant powered by Groq's ultra-low latency inference engine. Get instant responses for tuning advice, build planning, troubleshooting, and performance optimization. The AI communicates securely with the backend via Firebase.

### 🏎️ Community Feed
A real-time social feed where users can post builds, share garage updates, and interact with other enthusiasts. Powered by Firebase Realtime Database for instant, page-reload-free updates.

### 🛒 Car Marketplace
A dedicated space for buying and selling car parts. Users can list items, browse inventory, and connect with other enthusiasts directly through the platform.

### 📊 Market Value Estimator
Built using Python and data analytics techniques to organize and process pricing data — giving users accurate and reliable market value insights for JDM and performance vehicles.

### 🔧 Automotive Tools
A wide range of enthusiast-focused tools including:
- Performance calculators (horsepower, boost, drivetrain loss, gear speeds)
- Market value estimators for JDM cars
- A curated sound library of iconic engines
- Educational content covering performance modifications (suspension, brakes, induction, and more)
- A personal garage for tracking car modifications

### 🔐 Authentication & User Management
Secure login, session handling, and persistent user state via Firebase Authentication. Users can create accounts, save builds, post content, and access personalized features.
